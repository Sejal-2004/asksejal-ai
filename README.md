# 🤖 AskSejal AI

### Your AI-Powered Learning Buddy

AskSejal AI is a **Generative AI-powered learning assistant** built with **Python, Streamlit, and Google Gemini**.

It helps learners understand difficult topics in simple language, explore real-life examples, ask questions, and generate quizzes for practice.

> 🎓 Developed as part of the **AI EMPOW(H)ER Program by Infosys Springboard**

## 💻 Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/Sejal-2004/asksejal-ai.git
cd asksejal-ai
```

### 2. Install dependencies

```bash
pip install -r requirements.txt
```

### 3. Add your Gemini API Key

Create:

```text
.streamlit/secrets.toml
```

Add:

```toml
GEMINI_API_KEY = "your_api_key_here"
```

> 🔐 Never commit your API key or `secrets.toml` containing real credentials to GitHub.

### 4. Run the app

```bash
streamlit run app.py
```
